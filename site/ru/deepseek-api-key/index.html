2

Создайте и скопируйте API-ключ

  1. Откройте раздел API keys на платформе DeepSeek.
  2. Создайте новый ключ и дайте ему понятное имя, например Chitchat Buddy.
  3. Сразу скопируйте ключ целиком и храните его в закрытом месте, пока не сохраните в Buddy. Ключи DeepSeek обычно начинаются с sk-.
Никому не передавайте ключ. По условиям открытой платформы DeepSeek вы отвечаете за использование и расходы, вызванные утечкой ключа. Не вставляйте его в снимки экрана, отзывы, исходный код или веб-приложение, работающее в браузере.

3

Проверьте баланс и оплату

Создание ключа не гарантирует, что на счёте API есть средства. Откройте Top up, внесите только комфортную для вас сумму и периодически проверяйте использование.

  • 401 Authentication Fails обычно означает, что ключ неверен или скопирован не полностью.
  • 402 Insufficient Balance означает, что счёт API нужно пополнить.
  • В текущем FAQ DeepSeek перечислены PayPal, банковская карта, Alipay и WeChat Pay, но доступность может различаться.

4

Подключите ключ к Chitchat Buddy

При первой настройке: в поле платформы чат-бота выберите DeepSeek · мой API-ключ, вставьте ключ и нажмите Загрузить и настроить.

После настройки: откройте настройки Buddy, найдите Ключи облачных поставщиков, вставьте ключ в поле API-ключ DeepSeek и нажмите Сохранить предоставленные ключи. Затем выберите DeepSeek в разделе Поставщик языкового ИИ и нажмите Использовать выбранный.

Как Buddy защищает ключ: он хранится в защищённом пользовательском хранилище учётных данных вашей операционной системы. После сохранения Buddy очищает видимое поле и больше не показывает существующий ключ.
5

Поддерживает ли DeepSeek нулевое хранение данных?

В опубликованных документах нет гарантии, что прямой API DeepSeek работает с нулевым хранением данных (ZDR). Считайте и собственный ключ DeepSeek, и ограниченный доступ Buddy облачной обработкой без ZDR.

  • Условия открытой платформы не обещают ZDR. Они описывают обработку входных данных API для получения результата и требуют, чтобы разработчики приложений раскрывали правила последующей обработки персональных данных.
  • Текущая общая политика конфиденциальности DeepSeek прямо говорит, что не определяет правила обработки данных конечных пользователей в сторонних приложениях. Для охватываемых ею сервисов DeepSeek указывает, что может собирать запросы и входные данные, использовать информацию для улучшения или обучения технологии и хранить персональные данные по мере необходимости.
  • Политика позволяет отказаться от использования данных для обучения модели. Это ограничивает один способ использования, но не равнозначно нулевому хранению.
  • DeepSeek сообщает, что собираемые персональные данные обрабатываются и хранятся в Китайской Народной Республике.
  • Документация API также описывает автоматическое кеширование контекста на диске. Поэтому запрос без состояния нельзя понимать как «ничего не хранится».

Ограниченный шлюз Buddy хранит хеши ключей и числовые данные об использовании, а не текст диалога. Запрошенный текст всё равно поступает в DeepSeek, поэтому устройство шлюза не превращает вышестоящий API в сервис с ZDR.

Практическое правило: не отправляйте пароли, закрытые ключи, медицинские записи, конфиденциальные сведения о встречах или текст, которым вы не вправе делиться. Если текст должен оставаться на компьютере, выберите локальный Qwen в Buddy.
