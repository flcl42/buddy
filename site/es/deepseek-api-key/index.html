Antes de empezar

  • Usa una cuenta que controles y puedas recuperar.
  • Ten un método de pago compatible si no hay saldo promocional.
  • Mantén la nueva clave en secreto; trátala como una contraseña.
  • Usa Qwen local para texto que nunca deba salir de tu equipo.

Crea una cuenta o inicia sesión

  1. Abre la plataforma oficial de DeepSeek.
  2. Elige la opción de registro o acceso disponible en tu región.
  3. Completa las verificaciones de correo, teléfono, edad o identidad que solicite la plataforma.

DeepSeek Open Platform y el servicio de chat usan la misma cuenta. No compres una cuenta ni una clave a un vendedor externo.

Registrarse o acceder ↗
2

Crea y copia la clave API

  1. Abre API keys en DeepSeek Platform.
  2. Crea una clave y asígnale un nombre reconocible, por ejemplo Chitchat Buddy.
  3. Copia la clave completa de inmediato y mantenla en privado hasta guardarla en Buddy. Las claves de DeepSeek suelen empezar por sk-.
No compartas la clave. Los términos de Open Platform te responsabilizan del uso y los cargos provocados por una filtración. No la pegues en capturas, comentarios, código fuente ni aplicaciones web del navegador.

3

Comprueba el saldo y la facturación

Crear una clave no garantiza que la cuenta API tenga saldo utilizable. Abre Top up, añade solo el importe que te resulte cómodo y revisa el consumo periódicamente.

  • 401 Authentication Fails suele indicar que la clave es incorrecta o está incompleta.
  • 402 Insufficient Balance significa que la cuenta API necesita saldo.
  • La FAQ actual de DeepSeek menciona PayPal, tarjeta bancaria, Alipay y WeChat Pay, aunque la disponibilidad puede variar.

4

Conecta la clave a Chitchat Buddy

Durante la configuración inicial: en Chatbot platform elige DeepSeek · my API key, pega la clave y pulsa Download and set up.

Después de la configuración: abre los ajustes de Buddy, busca Cloud provider keys, pega la clave en DeepSeek API key y pulsa Save provided keys. Después selecciona DeepSeek en AI language provider y pulsa Use selected.

Cómo la protege Buddy: la clave se guarda en el almacén seguro de credenciales del usuario del sistema operativo. Buddy vacía el campo visible después de guardarla y nunca vuelve a mostrar una clave existente.
5

¿DeepSeek ofrece retención cero de datos?

No existe una garantía pública de que la API directa de DeepSeek tenga retención cero de datos. Considera tanto tu propia clave como el acceso limitado de Buddy a DeepSeek como procesamiento en la nube sin ZDR.

  • Los términos de Open Platform no prometen ZDR. Describen cómo las entradas de la API se procesan para producir salidas y exigen que los desarrolladores informen sobre el tratamiento de datos personales en sus aplicaciones.
  • La política general de privacidad actual dice expresamente que no cubre las reglas de tratamiento de usuarios finales dentro de aplicaciones externas. Para los servicios que sí cubre, DeepSeek indica que puede recopilar prompts y entradas, usar información para mejorar o entrenar su tecnología y conservar datos personales cuando sea necesario.
  • La política permite rechazar el uso para entrenamiento. Eso limita un uso concreto, pero no equivale a retención cero.
  • DeepSeek afirma que los datos personales que recopila se procesan y almacenan en la República Popular China.
  • La documentación de la API también describe caché de contexto automática en disco. Una API sin estado no debe interpretarse como «no se almacena nada».

La pasarela limitada de Buddy guarda hashes de claves y cifras de uso, no el texto del diálogo. El texto solicitado sí llega a DeepSeek, así que este diseño no convierte la API externa en ZDR.

Regla práctica: no envíes contraseñas, claves privadas, historiales médicos, detalles confidenciales de reuniones ni texto que no estés autorizado a compartir. Elige Qwen local cuando el texto deba permanecer en tu ordenador.
