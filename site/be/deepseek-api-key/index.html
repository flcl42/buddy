Праверце баланс і аплату

Стварэнне ключа не гарантуе наяўнасць даступнага балансу API. Адкрыйце Top up, унясіце толькі прымальную для вас суму і рэгулярна правярайце выкарыстанне.

  • 401 Authentication Fails звычайна азначае, што ключ няправільны або няпоўны.
  • 402 Insufficient Balance азначае, што ўліковы запіс API трэба папоўніць.
  • Бягучы FAQ DeepSeek пералічвае PayPal, банкаўскую картку, Alipay і WeChat Pay, але даступнасць можа адрознівацца.

Ці мае DeepSeek нулявое захоўванне даных?

Няма апублікаванай гарантыі, што прамы API DeepSeek не захоўвае даныя. Лічыце і ўласны ключ, і абмежаваны доступ Buddy да DeepSeek воблачнай апрацоўкай без ZDR.

  • Умовы Open Platform не абяцаюць ZDR. Яны апісваюць апрацоўку ўводу API у вывад і патрабуюць ад распрацоўшчыкаў праграм раскрываць правілы апрацоўкі асабістых даных.
  • Бягучая агульная палітыка прыватнасці наўпрост кажа, што не ахоплівае правілы апрацоўкі даных канчатковых карыстальнікаў у старонніх праграмах. Для сэрвісаў, якія яна ахоплівае, DeepSeek паведамляе, што можа збіраць запыты і ўвод, выкарыстоўваць інфармацыю для паляпшэння або навучання тэхналогій і захоўваць асабістыя даныя паводле патрэбы.
  • Палітыка дазваляе адмовіцца ад выкарыстання даных для навучання мадэляў. Гэта абмяжоўвае адну мэту выкарыстання, але не азначае нулявое захоўванне.
  • DeepSeek паведамляе, што сабраныя асабістыя даныя апрацоўваюцца і захоўваюцца ў Кітайскай Народнай Рэспубліцы.
  • Дакументацыя API таксама апісвае аўтаматычнае кэшаванне кантэксту на дыску. Таму API без стану не азначае «нічога не захоўваецца».

Абмежаваны шлюз Buddy захоўвае хэшы ключоў і лікавыя звесткі пра выкарыстанне замест тэксту дыялогу. Патрэбны тэкст усё адно трапляе ў DeepSeek, таму такі шлюз не робіць знешні API сэрвісам ZDR.

Практычнае правіла: не адпраўляйце паролі, прыватныя ключы, медыцынскія звесткі, канфідэнцыйныя дэталі сустрэч або тэкст, якім вы не маеце права дзяліцца. Выбірайце лакальны Qwen, калі тэкст павінен застацца на вашым камп'ютары.
